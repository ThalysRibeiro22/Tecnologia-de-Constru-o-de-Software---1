# Evidências da Etapa 05

Esta pasta reúne as capturas de tela que demonstram a comunicação assíncrona do sistema: consulta e envio de dados à API, estados de carregamento e mensagens de sucesso.

## Capturas

| Arquivo | O que demonstra |
|---|---|
| `evidencia-01-consulta-get-projetos.png` | Painel com os projetos carregados e, no DevTools, a requisição `GET /api/projetos` com status 200 |
| `evidencia-02-carregando-projetos.png` | Painel exibindo "Carregando projetos..." enquanto a consulta é feita |
| `evidencia-03-sucesso-consulta.png` | Painel com a mensagem "5 projetos carregados." após a consulta |
| `evidencia-05-botao-salvando.png` | Botão "Salvando..." durante o envio do cadastro de cliente |
| `evidencia-06-sucesso-cadastro.png` | Cadastro de cliente concluído, com a mensagem de sucesso e a lista atualizada |
| `evidencia-07-carregando-clientes.png` | Página de clientes exibindo "Carregando clientes..." enquanto a lista é consultada |
| `evidencia-08-post-projeto.png` | Projeto cadastrado, com a confirmação na tela e, no DevTools, a requisição `POST /api/projetos` com status 201 |
