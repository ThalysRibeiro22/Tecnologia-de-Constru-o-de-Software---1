# Evidências da Etapa 04

Esta pasta reúne os registros visuais das funcionalidades interativas implementadas com JavaScript no MadeiraFlow. As evidências demonstram o funcionamento normal, as validações, os estados sem resultado e a persistência dos dados entre as páginas.

## Registros

| Arquivo | Situação registrada |
|---|---|
| `evidencia-01-busca-funcionando.png` | `index.html` com termo no campo "Cliente" e somente os projetos correspondentes visíveis. |
| `evidencia-02-validacao-cliente.png` | `cliente.html` com formulário inválido e mensagens de erro visíveis. |
| `evidencia-03-cliente-cadastrado.png` | `cliente.html` após cadastro válido, com novo cliente na lista e mensagem de sucesso. |
| `evidencia-04-validacao-projeto.png` | `novo-projeto.html` com formulário inválido e mensagens de erro visíveis. |
| `evidencia-04b-projeto-confirmado.png` | `novo-projeto.html` após cadastro válido, com confirmação do novo projeto. |
| `evidencia-05-busca-sem-resultado.png` | `index.html` com busca sem correspondência e mensagem "Não encontramos projetos para essa busca.". |
| `evidencia-06-cliente-no-select.png` | `novo-projeto.html` com cliente cadastrado anteriormente disponível no campo "Cliente". |
| `evidencia-07-projeto-no-painel.png` | `index.html` com projeto criado em `novo-projeto.html` presente entre os cards. |

## Abrangência das evidências

O conjunto demonstra os requisitos de manipulação do DOM, tratamento de eventos, validação de formulários, alteração dinâmica da interface, tratamento de situações inválidas e persistência via `localStorage`. As evidências 6 e 7 registram especificamente a integração de dados entre as páginas de clientes, novos projetos e painel.
